# راهنمای نصب و آماده‌سازی محل (SITE_SETUP)

این راهنما برای نصاب و پشتیبان فنی است: آماده کردن رایانه‌ها، شبکه، سرور SQL، نصب برنامه و دستگاه‌ها.

---

## ۱. چک‌لیست هر رایانه (سرور و همه درب‌ها)

| کار | تنظیم | چرا |
|---|---|---|
| BIOS | `Restore on AC Power Loss = Power On` | بعد از برگشت برق، رایانه خودش روشن شود |
| ورود خودکار ویندوز | کاربر محلی مخصوص پارکینگ با ورود خودکار (`netplwiz`) | بدون نیاز به اپراتور بالا بیاید |
| اجرای خودکار برنامه | گزینه «اجرای خودکار هنگام روشن شدن ویندوز» در برنامه نصب | |
| خواب | `Sleep = Never` (خاموش شدن صفحه نمایش اشکالی ندارد) | ساعت‌شمار و همگام‌سازی قطع نشود |
| به‌روزرسانی ویندوز | Active hours: ۰۸:۰۰ تا ۲۲:۰۰ | ری‌استارت در ساعت کار انجام نشود |
| یو‌پی‌اس | برای رایانه‌ها، **سوییچ شبکه و دوربین‌ها** | با قطع برق کوتاه، ارتباط و دوربین قطع نشود |
| ساعت | همه رایانه‌ها با سرور هم‌زمان: `w32tm /config /manualpeerlist:"<نام سرور>" /syncfromflags:manual /update` | قیمت از روی زمان ورود و خروج حساب می‌شود؛ برنامه اختلاف بیش از ۶۰ ثانیه را هشدار می‌دهد |
| درایو داده | پوشه اطلاعات روی درایو غیر از ویندوز (مثلاً `D:\CaspianParking`) | با نصب دوباره ویندوز از بین نرود |
| آنتی‌ویروس | پوشه برنامه و پوشه اطلاعات را از اسکن لحظه‌ای مستثنا کنید | سرعت پایگاه‌داده |

## ۲. سرور

1. **SQL Server Express 2022** را نصب کنید (Instance: `SQLEXPRESS`، Mixed Mode اگر از ورود SQL استفاده می‌کنید).
2. سرویس‌های `SQL Server (SQLEXPRESS)` و `SQL Server Browser` را روی **Automatic** بگذارید.
3. در *SQL Server Configuration Manager* پروتکل TCP/IP را فعال کنید و در فایروال ویندوز درگاه ۱۴۳۳ (و UDP 1434 برای Browser) را **فقط برای آدرس درب‌ها** باز کنید.
4. یک پایگاه‌داده خالی بسازید: `CREATE DATABASE parking;` سپس `ALTER DATABASE parking SET READ_COMMITTED_SNAPSHOT ON;`
5. دسترسی: یا حساب ویندوز کاربر پارکینگ هر رایانه (Windows Authentication) یا یک ورود SQL با دسترسی `db_owner` روی `parking`.
6. **ODBC Driver 18 for SQL Server** را روی سرور و همه درب‌ها نصب کنید (برنامه نصب اگر نباشد هشدار می‌دهد).
7. برنامه نصب را اجرا کنید و گزینه **«نصب سرویس سرور»** را تیک بزنید. این سرویس گزارش روزانه، پشتیبان‌گیری، تمدید کیف پول و حالت نگهبانی شب را حتی بدون باز بودن برنامه انجام می‌دهد.
8. برنامه را یک بار باز کنید؛ در راه‌اندازی اولیه نقش **سرور** را انتخاب کنید، نام سرور (مثلاً `PC-SERVER\SQLEXPRESS`) و پایگاه‌داده `parking` را بدهید و «آزمایش اتصال» را بزنید. در پایان کاربر مدیر را بسازید.
9. یک پوشه اشتراکی برای به‌روزرسانی بسازید (مثلاً `\\PC-SERVER\ParkingUpdates`) با دسترسی **خواندن** برای کاربران درب‌ها و آدرس آن را در «تنظیمات ← سرور و همگام‌سازی ← به‌روزرسانی خودکار» وارد کنید.

## ۳. درب‌ها

1. برنامه نصب را اجرا کنید (بدون گزینه سرویس).
2. در راه‌اندازی اولیه نقش **درب** را انتخاب کنید، شماره درب (۱، ۲، …) و نام آن را وارد کنید. **شماره هر درب باید یکتا باشد**؛ شماره رسیدها بر همین اساس تکرار نمی‌شوند.
3. اطلاعات سرور را بدهید و «آزمایش اتصال» را بزنید. در پایان، درب **به سرور می‌پیوندد**: کاربران، تعرفه‌ها، مشترکین و کلید امضای رسید از سرور گرفته می‌شود.
   - پیوستن فقط برای رایانه‌ای ممکن است که هنوز تردد یا پرداختی ثبت نکرده. پایگاه‌داده قبلی پاک نمی‌شود؛ با نام `local.prejoin-….db` کنار گذاشته می‌شود.
4. در نوار بالای برنامه باید «ارتباط با سرور: برقرار» دیده شود. اگر ارتباط قطع شود درب به کار ادامه می‌دهد و پس از وصل شدن، همه چیز خودکار ارسال می‌شود.

## ۴. چاپگر رسید (۸۰ میلی‌متری)

1. درایور ویندوز چاپگر را نصب کنید، عرض کاغذ ۸۰ میلی‌متر، حاشیه صفر.
2. «تنظیمات ← دستگاه‌ها ← چاپگر»: نوع «درایور ویندوز» و نام چاپگر را انتخاب کنید و «چاپ آزمایشی» بزنید.
3. اگر چاپگر با درایور ویندوز تصویر را درست چاپ نمی‌کند، نوع «ESC/POS خام» را امتحان کنید.
4. لوگو در `<پوشه اطلاعات>\receipt\logo.png`، جداکننده در `receipt\divider.png`، تصاویر هنری بارکد در `receipt\barcode-art\`.

## ۵. بارکدخوان

- بارکدخوان USB (حالت کیبورد): نیازی به تنظیم ندارد؛ «تنظیمات ← دستگاه‌ها ← آزمایش بارکدخوان» را با یک رسید امتحان کنید.
- بارکدخوان سریال: نوع «سریال» و درگاه COM.
- اسکنر باید **Code 128** را بخواند و در پایان Enter بفرستد.

## ۶. دوربین و پلاک‌خوان

- «تنظیمات ← دستگاه‌ها ← دوربین‌ها»: برای هر مسیر (ورود/خروج) یک دوربین.
- **دوربین پلاک‌خوان هوشمند**: نوع «هوشمند» و یک درگاه (مثلاً ۸۰۸۱). دوربین باید به `http://<IP درب>:<درگاه>/plate` اطلاعات بفرستد (قالب در `docs/ANPR_PLUGINS.md`). درگاه را در فایروال فقط برای IP دوربین باز کنید.
- **دوربین شبکه معمولی (RTSP)**: آدرس RTSP و یک موتور پلاک‌خوان دارای مجوز تجاری (افزونه) لازم است؛ راهنما در `docs/ANPR_PLUGINS.md`. بدون موتور، تصویر زنده دیده می‌شود و پلاک دستی وارد می‌شود.
- حداقل اطمینان پیش‌فرض ۸۰٪ است؛ پایین‌تر از آن پلاک فقط پیشنهاد می‌شود.
- عکس‌ها در `<پوشه اطلاعات>\photos\سال\ماه\روز` ذخیره می‌شوند؛ مدت نگه‌داری در «پشتیبان و سیستم ← عکس‌ها».

## ۷. راهبند، کارت‌خوان، کارتخوان بانکی، تابلو

| دستگاه | تنظیم | آزمایش |
|---|---|---|
| راهبند | رله USB/سریال (درگاه COM و فرمان باز/بسته به هگز)، رله شبکه (`IP:درگاه`) یا رله وب (آدرس URL) | «آزمایش راهبند» |
| کارت‌خوان تردد | USB (مثل بارکدخوان)، سریال، یا UHF شبکه (`IP:درگاه`) | کارت را در پرونده مشترک ثبت و در درب نزدیک کنید |
| کارتخوان بانکی | تا رسیدن مستندات بانک «دستی» است | «آزمایش کارتخوان» |
| تابلوی LED | سریال یا شبکه (متن یک خطی UTF-8) | «آزمایش تابلو» |

فرمان پیش‌فرض رله (`A0 01 01 A2` باز، `A0 01 00 A1` بسته) برای اغلب رله‌های USB رایج است؛ برای مدل دیگر از دفترچه رله بگیرید.

## ۸. پشتیبان‌گیری

- پشتیبان روزانه خودکار در `<پوشه اطلاعات>\backups` و هنگام بستن برنامه.
- حتماً یک **مقصد دوم** (دیسک دیگر یا USB) در «پشتیبان و سیستم ← پشتیبان» اضافه کنید.
- برای سرور: پشتیبان SQL Server (`.bak`) با سرویس سرور گرفته می‌شود؛ مسیر آن را روی دیسک دوم بگذارید.
- ماهی یک بار «آزمایش بازیابی» را روی یک پشتیبان اجرا کنید.

## ۹. به‌روزرسانی

- نسخه جدید: فایل `…-Setup-<نسخه>.exe` و `version.json` را در پوشه اشتراکی به‌روزرسانی کپی کنید.
- درب‌ها هنگام باز شدن برنامه (پیش از ورود کاربر) نسخه جدید را بی‌صدا نصب و برنامه را دوباره باز می‌کنند.
- سرور و رایانه تک‌دستگاهی را با اجرای همان فایل نصب به‌روزرسانی کنید.

## ۱۰. حذف برنامه

حذف برنامه **پوشه اطلاعات را پاک نمی‌کند** (پایگاه‌داده، عکس‌ها، پشتیبان‌ها). برای انتقال به رایانه جدید: برنامه را نصب کنید و در راه‌اندازی اولیه همان پوشه اطلاعات را انتخاب کنید، یا از «پشتیبان و سیستم ← بازیابی» استفاده کنید.
